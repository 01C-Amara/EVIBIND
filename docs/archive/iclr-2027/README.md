# ICLR 2027 planning documents (archived)

ICLR 2027 was the first intended venue for the EviBind paper. **The paper was
not submitted to ICLR 2027.** It is being prepared for
[TMLR](https://jmlr.org/tmlr/) instead, where the absence of a page limit lets
the per-suite results, residual breakdowns and limitations stay in the main
text rather than being cut to fit nine pages.

These files are kept for the record of how the paper's claims were narrowed.
None of them is evidence:

| File | What it is |
|---|---|
| `ICLR_STRONG_ACCEPT.md` | an internal evidence ledger written against ICLR's review criteria |
| `ICLR_STRONG_ACCEPT_REVISION_PLAN.md` | the revision plan that ledger produced |
| `ICLR_SYNTHETIC_REVIEW_PANEL.md` | an **AI-simulated** review panel; no human reviewed anything |

"Strong accept" in two of the filenames is the target those documents were
written toward, not a verdict anyone gave. Several claims they assess have
since been retracted or narrowed - most visibly the AgentDojo banking result
(`docs/FINDINGS.md` §19 and §23) - so read them as history, not as the current
state of the evidence.
